# WebApp UX 规范（v2）

> 模式：**Operate**（主）+ **Read**（书页预览）。
> 读者 = 一个刚把书拖进来、还不知道要花多少钱的人；和一个守着长任务的人。
> 依据：`PRODUCT.md`、`docs/design-v2.md`、`docs/ux/cli.md`。
> 技术前提：Vite + TypeScript（用户已确认）；后端仍是 FastAPI。
> 本文件是实现契约：信息架构、状态、组件词汇、token、响应式、无障碍都可据此验收。

---

## 1. 设计论点

**这不是仪表盘，是一张摊在书桌上的稿纸。**

工具区（chrome）密集、冷静、信息优先；书页（sheet）安静、留白、真的像一页书。
两者并置产生的张力就是这个产品的性格：**左边是机器的账本，右边是即将读的书。**

三个必须同时成立的承诺：

1. **你随时看得见这本书长到哪了**——不是进度条，是真的书页在长大。
2. **你随时看得见你花了多少钱**——数字常驻，不藏在设置里。
3. **你在成品上工作**——校对批注直接落在书页上，不是另一个表格里的另一份文本。

### 明确拒绝的形态

- ❌ 一排同尺寸卡片（图标 + 标题 + 文字）当书架
- ❌ 指标卡堆（一个大数字 + 小标签）
- ❌ 章节眉（kicker/eyebrow）压在标题上方
- ❌ 渐变文字、玻璃拟态、发光边缘
- ❌ 用 emoji 当图标
- ❌ 把"翻译中"藏进一个日志页
- ❌ 深色模式（见 §7 决策）

## 2. 信息架构

四个一级目的地，左侧导航（窄轨，图标 + 文字，纵向）：

```
┌────────────────────────────────────────────────────────────┐
│  booktran            《银色天空》 · 简体中文 ▾        ⚙ ⌘K   │ ← 顶栏 48px
├──────────┬─────────────────────────────────────────────────┤
│  书架    │                                                 │
│  工作台  │                主区                              │
│  模型    │                                                 │
│  成本    │                                                 │
├──────────┴─────────────────────────────────────────────────┤
│  识别 ✓  翻译 ●  校对 ○  排版 ○      ▕████████▏ 53%  $2.14 │ ← 常驻作业条 44px
└────────────────────────────────────────────────────────────┘
```

| 目的地 | 什么时候来 | 核心问题 |
|---|---|---|
| **书架** | 开始时、回来时 | "我有哪些书？哪本没翻完？" |
| **工作台** | 干活时 | "这本书现在是什么样？我的批注在哪儿？" |
| **模型** | 配置时 | "谁在干活？贵不贵？" |
| **成本** | 心疼时 / 复盘时 | "钱花到哪去了？" |

**常驻作业条**（底部）是产品的节奏中心：任何页面都能看到阶段、进度、花费，
点击展开当前动作的明细。它替代了"日志页"作为进度的主要出口——日志退到工作台内的次级面板。

## 3. 书架（Library）

### 3.1 空状态 = 教学，不是"这里什么都没有"

首次打开（无任何项目）时，主区不是空白，而是**四步教学**，右侧放一个真实的示例项目预览：

```
┌──────────────────────────────────────────────────────────────┐
│  把一本书变成你能读的语言                                    │  ← 标题自带分量
│                                                              │
│  1  放进你的书        EPUB · PDF · TXT · MOBI · 图片          │
│     ┌──────────────────────────────────────┐                 │
│     │  拖到这里，或点击选择文件            │  ← 主行动区     │
│     └──────────────────────────────────────┘                 │
│                                                              │
│  2  选你要的语言        简体中文 · English · 日本語 …        │
│                                                              │
│  3  选排版方式          参照原排版 · 模型设计 · 混合          │
│                                                              │
│  4  看清价格再开始      开始前会告诉你这次大概要花多少钱      │
│                                                              │
│  没有书？  用示例书试试 →                                    │
└──────────────────────────────────────────────────────────────┘
```

- 主行动只有一个：**拖入文件**。其余三步是说明，不是三个表单。
- 「用示例书试试」：内置一本 12 段的公共领域短篇，用假 provider 跑通全流程，
  零成本、不需要 key。这是公开用户的第一条成功路径。
- 首次使用**不要求先填 key**；`doctor` 的提示以非阻塞的横幅出现在顶栏，
  而不是拦住用户。

### 3.2 有项目时：列表，不是卡片墙

密度是工具界面的许可。书架用**行列表**，一行一本书：

```
┌────────────────────────────────────────────────────────────────────────┐
│  银色天空.epub          EPUB · 日语 → 简体中文      ▕██████▏ 53%  $2.14  │
│  上次活动 2 分钟前 · claude-sonnet-4-5 · 1,284/2,417 段                │
├────────────────────────────────────────────────────────────────────────┤
│  银河系漫游指南.pdf    PDF · 英语 → 简体中文        ▕░░░░░░░░   0%  $0    │
│  昨天创建 · 待开始 · 扫描件 340 页                                     │
├────────────────────────────────────────────────────────────────────────┤
│  术语学讲义.txt        TXT · 日语 → 简中/English   ▕██████████ 100% $4.02 │
│  3 天前完成 · 可导出 EPUB/PDF                                           │
└────────────────────────────────────────────────────────────────────────┘
```

- 进度用**条**不用环（环是"仪表盘"信号，且在列表里对齐困难）。
- 金额右对齐、等宽数字（tabular-nums），一眼能比大小。
- 悬停一行时出现操作（继续 / 预览 / 导出 / 删除），不用进详情页。
- 排序：默认"最近活动"；可切"未完成优先 / 按花费"。

## 4. 工作台（Workspace）— 核心

三栏，比例 `240px | 1fr | 340px`（右栏可折叠到 0）。

```
┌──────────┬────────────────────────────────┬────────────────────────┐
│ 大纲     │                                │  校对                  │
│          │      ┌──────────────────┐      │  ┌──────────────────┐  │
│ 第1章    │      │                  │      │  │ 第2章 · 第14段   │  │
│  第1章 ✓ │      │   书  页  预  览   │      │  │ 术语「魔导器」   │  │
│  第2章 ● │      │                  │      │  │ 译为「导魔器」   │  │
│  第3章 ○ │      │  ┌────────────┐  │      │  │ [ 接受建议 ]     │  │
│          │      │  │            │  │      │  └──────────────────┘  │
│ 阶段     │      │  │  真正的    │  │      │  ┌──────────────────┐  │
│ 识别 ✓   │      │  │  书  页    │  │      │  │ 第3章 · 第2段    │  │
│ 翻译 ●   │      │  │            │  │      │  │ 疑似未翻译       │  │
│ 校对 ○   │      │  └────────────┘  │      │  │ [ 手动改写 ]     │  │
│ 排版 ○   │      │   第 12 / 340 页  │      │  └──────────────────┘  │
│          │      │  ‹ 上一页  下一页›│      │  12 个问题 · 3 个待复核 │
└──────────┴────────────────────────────────┴────────────────────────┘
```

### 4.1 中栏 = 活页预览（签名交互）

这是整个产品的**签名体验**：书页随翻译进程实时长出来。

- **它真的是一页书**：白纸、真实页边距、页码、衬线字体、65–70ch 行长、
  段首缩进两字、标题有层级。不是"一段段文字列表"。
- **它是分页的**：左栏点章节 → 中栏跳到该章首页；底部有页码与翻页。
- **未译段落显示原文**，并用左侧 3px 靛蓝竖条标记"待译"，
  翻完即变成正常段落（竖条消失，文字替换）——**这是唯一的编排动效**：
  段落落定时 180ms 淡入 + 上移 4px，不抢注意力。
- **批注直接标在页面上**：有问题的地方用靛蓝下划线 + 右侧页边距的小标记；
  点标记 → 右栏滚动到对应问题；点问题 → 中栏滚动并高亮那一段。
- **渲染范围**：只渲染可视的 2–3 页（虚拟滚动），否则长书会卡。

### 4.2 左栏 = 大纲 + 阶段

- 上半：章节列表（来自 EPUB spine / PDF 目录 / TXT 段落分组），每章一个状态点。
- 下半：阶段轨道（识别 / 翻译 / 校对 / 排版），每阶段显示进度与"重跑"入口。
- 折叠后只剩一条 48px 窄轨，保留阶段点。

### 4.3 右栏 = 校对

问题清单来自规则质检 + 模型润色建议，按严重度排序：

```
第2章 · 第14段          术语不一致
原文  魔导器
译文  导魔器            ← 与术语表「魔导器」不符
      [ 接受建议 ]  [ 保留原文 ]  [ 忽略 ]
```

- 每条问题必须能**就地处理**（接受 / 保留 / 忽略），不必跳走。
- 处理后立即回写译文 → 中栏书页同步更新。
- 面板顶部：问题总数、按类别筛选（术语 / 复读 / 占位符 / 残留原文 / 长度异常）。

### 4.4 顶部项目切换器

顶栏中间是当前书 + 目标语言切换器。切换目标语言时，**整个工作台换语言**
（预览、批注、大纲状态都切换），费用进度保持各自独立显示。
这是 many-to-many 在 UI 上的落点，必须一眼可见"我在看哪种语言的版本"。

## 5. 模型（Models）

面向"配置一个或多个大模型"的需求，这一页必须让用户看见**谁在干什么活**。

```
┌────────────────────────────────────────────────────────────────────┐
│  模型档案                                          [ 新建档案 ]     │
│                                                                    │
│  名称        能力      模型              价格 in/out     状态      │
│  claude      文本+视觉 claude-sonnet-4-5  $3.00 / $15.00  ● 已连通 │
│  qwen-local  文本      qwen2.5:7b         $0.00 / $0.00   ● 已连通 │
│  gemini-vl   视觉      gemini-2.5-pro     $1.25 / $10.00  ○ 未测试 │
│  paddle-ocr  OCR       pp-ocr-v4          本地            ● 就绪   │
├────────────────────────────────────────────────────────────────────┤
│  角色路由                                                            │
│  翻译        → claude          识别(VLM)  → gemini-vl             │
│  OCR         → paddle-ocr      校对       → claude                 │
│  排版设计    → gemini-vl        术语分析   → qwen-local            │
├────────────────────────────────────────────────────────────────────┤
│  级联规则（可选）                                     [ 添加规则 ]  │
│  段落 > 400 字            → claude-opus                             │
│  术语密度 > 0.5           → claude-opus                             │
│  目标语言 = 日语          → qwen-ja                                 │
└────────────────────────────────────────────────────────────────────┘
```

要点：
- **档案**与**角色**分开呈现，因为它们回答两个不同问题："有哪些端点"和"谁干什么活"。
- 价格写在档案上 → 成本页与此处同源，不会出现两个真相。
- 「已连通 / 未测试 / 不可用」三态明确，点一下能当场测连通性。
- 密钥只显示"已设置/未设置"，永不回显。
- **颗粒度分层**（评审挑衅性问题 5 的处置）：并发数、RPM、块预算 tokens、超时、
  重试次数这类调参项**收进"高级"折叠区**，默认收起；公开用户看到的是
  "谁在干什么活 + 大概花多少钱"，不是一屏参数。
  "模型"作为一级目的地保留，是因为需求明确要"配置一个或多个大模型（VLM/OCR 等）"，
  这本身是产品能力，不是调参。

## 6. 成本（Cost）

```
┌──────────────────────────────────────────────────────────────┐
│  本次 $3.42   本月 $18.06   预算 $5.00 / 本项目（已用 68%）     │
├──────────────────────────────────────────────────────────────┤
│  按阶段                                                        │
│  翻译      $3.31  ████████████████  96.8%                      │
│  识别      $0.09  █                                                 │
│  校对      $0.02  ▏                                                 │
├──────────────────────────────────────────────────────────────┤
│  按模型                                                        │
│  claude-sonnet-4-5   $3.31   输入 812k   输出 221k              │
│  paddle-ocr          $0.00   340 页                              │
├──────────────────────────────────────────────────────────────┤
│  按目标语言                                                    │
│  简体中文   $3.42                                                  │
└──────────────────────────────────────────────────────────────┘
```

- 数字一律等宽对齐，金额保留 2 位（小于 $0.01 显示 `<$0.01`）。
- 预算用条不用环；超预算时条变错误色并给出"提高上限"的直接入口。
- 未配置价格的档案显示 `—`，不显示 0（0 是有意义的数字，会撒谎）。

## 7. 视觉系统

### 7.1 颜色

**颜色策略：Restrained。** 一个交互强调色 + 完整的状态语义色 + 中性灰。
不承诺品牌色（目前无品牌资产，见 `PRODUCT.md`），不假装。

| token | 值 | 用途 |
|---|---|---|
| `--desk` | `#F5F6F7` | 工作台底色（"桌面"） |
| `--surface` | `#FFFFFF` | 面板、表格 |
| `--paper` | `#FFFFFF` | 书页（与面板同白，靠阴影区分） |
| `--ink` | `#14161A` | 主文字、主按钮底色 |
| `--ink-2` | `#39414E` | 次级文字 |
| `--ink-3` | `#5B6472` | 辅助文字（对 `--desk` 对比度 ≥ 5:1） |
| `--line` | `#E3E6EA` | 分隔线 |
| `--line-strong` | `#CDD3DA` | 边框、输入框 |
| `--accent` | `#2C5AA0` | 靛蓝：主链接、选中态、**校对批注** |
| `--accent-strong` | `#23477F` | 靛蓝深档：hover、主按钮描边 |
| `--danger` | `#B42318` | 错误 |
| `--warn` | `#B54708` | 警告 |
| `--ok` | `#027A48` | 成功 |
| `--mark` | `#2C5AA0` | 批注下划线（= `--accent`，不是第二套颜色） |

**为什么批注是靛蓝而不是朱红**：错误状态已经占用红色，批注再占红色会在同一屏
制造两个"红"；而且编辑行业惯例里**蓝笔=文字编辑、朱笔=文字校对**，
本产品的校对阶段正是文字编辑，用靛蓝既合规又与状态色不冲突。

### 7.2 字体

| 场景 | 字体 | 规格 |
|---|---|---|
| 界面文字 | 系统 sans 栈（`-apple-system, "Segoe UI", "Noto Sans", ...`） | 13px / 1.5 |
| 数字（费用、token、进度） | 同上 + `font-variant-numeric: tabular-nums` | 12–13px |
| **书页正文** | `Source Han Serif / Noto Serif CJK` 优先，回退 `Georgia, serif` | 18px / 1.9，两端对齐 |
| 书页西文 | `Source Serif / Noto Serif` | 18px / 1.9 |
| 代码/路径 | `ui-monospace, "JetBrains Mono", monospace` | 12px |

- 界面**一个字体族**足够（operate 原则）；书的衬线是**内容**，不是装饰。
- 固定 rem 台阶，不做流式字号：12 / 13 / 14 / 18 / 24 / 30。
  最大一级台阶 = 24 ÷ 13 ≈ 1.85（避免当前 UI "h1 14px vs 正文 13px"的扁平层级）。
- 书页行长 68ch（CJK 按 34 字/行），两侧留白自适应但上限 720px。

### 7.3 间距 / 圆角 / 阴影 / 动效

- 间距基数 4px：`4 8 12 16 20 24 32 48 64`。
  标题上方留白 ≥ 下方留白（4:1 视觉节奏）。
- 圆角：控件 3px，面板 6px，徽标才用胶囊。**不要一切都是胶囊。**
- 阴影（必须有偏移 + 模糊）：面板 `0 1px 2px rgba(20,22,26,.06), 0 4px 12px rgba(20,22,26,.08)`；
  书页 `0 1px 3px rgba(20,22,26,.10), 0 12px 32px rgba(20,22,26,.12)`。
- 动效：`120ms` 微交互 / `180ms` 面板 / `240ms` 书页落字；
  缓动 `cubic-bezier(.2,.8,.2,1)`；`prefers-reduced-motion` 下降为 0ms。
- **唯一的编排动效**：段落落定时的淡入上移。其余都是状态反馈。

### 7.4 深色模式决策

**v1 不做深色模式。** 理由：产品的主体内容是"一张纸上的书"，纸张在暗环境下
不变白；而只把工具壳做成暗色、书页仍然亮白，会得到一个刺眼且不真实的界面。
要支持暗色阅读，应当是"整页渲染器支持暗色纸张 + 屏幕亮度友好"的一件事，
而不是给界面加一套暗色变量。**这条写进 `PRODUCT.md` 的未决项**，等渲染器
支持反色纸张时再启用。

## 8. 状态清单（每个面板都必须有）

| 状态 | 表现 |
|---|---|
| 加载中 | **骨架屏**（结构同真实内容），不是居中转圈 |
| 空 | 教学式（教用户下一步），不是"暂无数据" |
| 出错 | 一句人话 + 一个恢复动作 + 可展开的原始细节（默认收起） |
| 部分完成 | 已完成的部分照常可用，失败部分就地标出，不整页拦截 |
| 超长内容 | 截断 + 悬浮显示全文；表格用虚拟滚动 |
| 断线（SSE 断开） | 顶栏出现"已断开 · 重连中"，并提供手动重连；不静默停止更新 |
| 预算超限 | 作业条变错误态 + 明确的下一步（提额 / 换模型 / 暂停） |
| 预览未生成 | 预览区显示"排版将在翻译开始后生成"，不是空白 |

**错误文案统一格式**（与 CLI 同源）：

```
翻译阶段失败：模型返回 429，已重试 4 次
  试试：降低并发（booktran role set translate=claude --concurrency 2）
  细节：HTTP 429 rate_limit_exceeded …
```

## 9. 响应式

| 宽度 | 布局 |
|---|---|
| ≥1440 | 三栏 `240 / 1fr / 340` |
| 1120–1439 | 三栏，右侧校对栏可折叠为图标条 |
| 768–1119 | 两栏：预览 + 折叠抽屉里的校对；大纲收成下拉 |
| <768 | 单栏：预览全宽；底部标签栏切换 预览 / 校对 / 大纲 / 日志 |

- 响应式是**结构性的**（折叠栏、换布局），不做流式字号。
- 书页在任何宽度下都保持 68ch / 720px 上限，居中；不因为窗口变窄就改变行宽。
- 触摸目标 ≥44px；作业条在窄屏折成两行。

## 10. 键盘与无障碍

### 键盘

| 键 | 动作 |
|---|---|
| `⌘K` / `Ctrl+K` | 命令面板（切书、切目标语言、跳阶段、导出） |
| `g` 然后 `o` | 打开书架 |
| `g` 然后 `w` | 打开工作台 |
| `空格` | 暂停 / 继续当前作业 |
| `j` / `k` | 在校对列表中上下移动 |
| `Enter` | 在问题条目上：接受建议 |
| `Esc` | 关闭面板 / 取消批注编辑 |
| `?` | 快捷键浮层 |

### 无障碍

- 对比度：正文 ≥4.5:1，大字 ≥3:1；`--ink-3` 对 `--desk` ≥5:1（已核对）。
- 状态**从不只用颜色**：进度条旁永远有百分比数字，错误色块必带文字标签。
- 作业进度通过 `aria-live="polite"` 播报（每 10% 一次，不要每秒念）。
- 标题层级连续：页面 `h1` → 区块 `h2` → 小节 `h3`（当前实现 h1→h3 跳级，必须修）。
- 表格：`<th scope="col">` + `<caption>`；行操作有 `aria-label`。
- 焦点：`2px` accent 描边 + 2px 偏移；焦点陷阱在对话框内，关闭后归还触发元素。
- 书页预览是可读区域，按语言设 `lang` 属性；朗读顺序 = 书的顺序。
- 所有动效尊重 `prefers-reduced-motion`。
- 文案层 i18n：zh-CN 默认，en-US 预留；数字/货币/日期按 locale 格式化。

## 12. 与 CLI 的关系

两者共享同一份**数据契约**，避免"两套真相"：

- 阶段状态、进度、费用，用同一套字段（与 CLI 的 NDJSON 事件同源）。
- CLI 是 Web 的降级路径：任何 Web 能做的事，CLI 都能用 `--json` 做到；
  任何 CLI 能做的事，Web 都有对应界面（除了终端专属的快捷键）。
- 书签、Web 里的编辑结果，CLI 的 `run` 立刻能看到（同一份 `state.json`）。

## 14. 来自评审的功能性硬要求（v2 实现必须满足）

> 下列每一条都来自对 v0.4 的实测评审（`docs/ux/review-webapp.md` §1.2），
> 是**功能缺陷**而非审美偏好，验收时逐条勾。
>
> **实现状态（v0.8）**：R1–R14 已在现有单页前端上修完（未换栈）——
> 停止/续跑（R1/R2）、反馈不撒谎（R3）、术语与背景单一写入口（R4）、
> 侧栏与顶栏进度随轮询刷新（R5）、结束即提示并给结算（R6）、导出可选且可下载（R7）、
> 输入有可访问名（R8）、交互元素是真控件（R9）、状态可播报（R10）、
> 日志只在内容变化时重写（R11）、侧栏分组降级为非标题 + 字号层级 13/14/17px（R12/R13）、
> 术语页空状态不再把人赶去改 JSON（R14）。
> v0.6–v0.8 又补上：阶段维度状态展示（`Track.stages`）、**SSE 事件流**（替代轮询）、
> 「校对」面板（问题清单 + 采用建议 + 修订历史）、「预览」活页（书页 HTML 实时刷新）。
> v0.9 已把前端重做为 **Vite + React + TypeScript**（`web/`）：书架（列表 + 空状态教学 + 示例书）、
> 工作台三栏（目录·阶段 | 活页 | 校对）、术语与背景（单一写入口）、模型档案与角色路由 + 预算闸、
> 成本四维明细、常驻作业条、⌘K 命令面板、SSE 事件流；令牌集中在 `web/src/tokens.css`。
> 仍未做：深色模式（见 §7.4 的决策）、把 EPUB/PDF 导出也接到 model 排版策略上。

| # | 要求 | 现状缺陷 |
|---|---|---|
| R1 | **作业可停止**：`POST /api/project/{pid}/cancel`，优雅暂停并落盘；UI 常驻"停止"按钮 | 后端无 cancel 路由，长任务无法中断 |
| R2 | **作业可续跑**：完成后"继续翻译"按钮必须复位可用；运行中才禁用 | 按钮 `disabled` 只设不复位，跑一次永久禁用 |
| R3 | **反馈不许撒谎**：所有写操作检查 `r.ok`，失败要显示后端原因 | `translate` 忽略 `r.ok`，后端拒绝也提示"翻译已启动" |
| R4 | **单一写入口 + dirty 检查**：术语/背景/设置合并为一次保存；任何未保存改动都有标记，切换上下文前提示 | 两个保存按钮各持一份快照，互相覆盖，**静默丢失编辑** |
| R5 | **进度永远新鲜**：所有进度数字随作业事件更新（含侧栏与顶栏），不做只在初始化时刷新 | 侧栏百分比在运行中全程冻结 |
| R6 | **完成必须有事件**：任务结束推 `job.finished`，UI 出现完成态与结算摘要 | 全书最贵的一刻零确认 |
| R7 | **导出可选且可取回**：格式/双语/语言显式选择；导出后给下载入口（后端 `/files`、`/file/{name}` 已存在但前端从未调用） | 写死双语 + txt，只给文件名 |
| R8 | **每个输入有可访问名**：`<label for>` 或包裹控件；语言选择用多选（数据源用代码里已有的 19 语言 `LANGS`，别再让用户手打代码） | 17 个 label 全无 `for`；`LANGS` 是死代码，UI 用自由文本 |
| R9 | **交互元素是真控件**：上传区、列表项、tab 用 `button`/`li>button` 或补 `role` + `tabindex` + 键盘事件；tab 用 `tablist/tab/tabpanel` + 方向键 | `div#drop` + `li[onclick]`，键盘用户无法上传也无法选项目 |
| R10 | **状态要能播报**：进度条 `role="progressbar"` + `aria-valuenow`；toast `role="status"` + `aria-live="polite"`；作业状态节流后播报 | 全站 `aria-*` 0 处 |
| R11 | **重渲染不许打断人**：列表增量更新，不整体重写 `textContent` | 日志每 2s 整体重写、概览每 3s 整块重渲染，滚动位置与选中文字被抹掉 |
| R12 | **控件同族**：`select`/`input`/`button` 的 padding、radius、focus-visible、loading 态统一 | 两套控件规格并存 |
| R13 | **布局不许双滚动**：`main` 高度用实际头部高度，不用写死的 `calc(100vh - 45px)` | 宽屏双滚动条；`#content` 960px 上限在宽屏留大片空白 |
| R14 | **术语可增删**：术语页内能加行、删行、改备注；空状态给"分析 → 补译名 → 保存"三步引导，不把人赶去改 JSON | 不能增删、备注只读、空状态指向 `glossary.json` |
