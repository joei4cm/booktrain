# Surface brief — booktran CLI（v2）

## 范围与访客模式
本地单用户的命令行工具。模式 **Operate**：读者正在完成一件长任务。
覆盖：`doctor / init / run / status / preview / export / cost / profile / role / serve / config / version`。
输出三形态：TTY 实时覆盖、管道逐行事件、`--json` NDJSON。
不含：全屏 TUI、鼠标交互、彩色 ASCII 艺术。

## 受众、任务、证据与约束
- 受众两类：把书翻给自己读的普通用户（第一次用 `doctor`），以及把翻译嵌进流水线的
  power user（要 JSON、要退出码、要可续跑）。
- 任务：守一场要跑几小时、会产生真实费用的翻译作业，并能随时暂停/续跑/查账。
- 证据：真实的 token 与费用、真实的阶段与段计数、真实模型名；不编造 ETA。
- 约束：Python ≥3.11、argparse、不引入 TUI 框架；遵守 `NO_COLOR`/`isatty`/`COLUMNS`；
  退出码语义化；所有交互都有非交互等价物；不使用 emoji 当图标。

## 选定方向与难忘瞬间
**方向**：校样稿纸的终端化身——一张单色的印刷账本行，数字贴右边缘对齐，
蓝色只标"你选的"，红色只标"坏了"。
**难忘瞬间**：开跑前的成本闸——
「即将开始翻译《银色天空》… 预计 $2.40 – $4.80 … [Enter] 开始 [c] 改配置 [q] 退出」，
把"这本书要花我多少钱"变成一个你按下回车之前就能看见、并且可以拒绝的事实。

## 未决
- NDJSON 字段名在 v1 前冻结，但 `cost` 的币种字段是否需要多币种，待第一批用户反馈。
- `doctor` 的连通性测试是否默认发 1-token 请求（会产生极小额费用），待确认。

## Direction contract

**THESIS**
CLI 面对的不是"跑一条命令"，而是"守一场要跑几小时的活"。
所以终端里常驻三件事：到哪了、花了多少、能不能停。
拒绝 v0.4 那种"每完成一块就 print 一行"的日志式输出——3000 段的书会刷出 3000 行。

**OWN-WORLD**
印刷账本行：单色前景色承载正文，靛蓝只用于"你选的/正在做的"，红色只用于"坏了"，
黄色只用于"注意"；数字（token、费用、时长、百分比）一律等宽并贴右边缘对齐；
分隔靠一条细横线而不是空行堆叠；阶段切换留下痕迹（不擦除），形成一条时间线。
不使用 emoji；不用符号堆砌当装饰。

**STORY**
你敲 `booktran run` → 它先告诉你这次要花多少钱并等你确认 → 然后终端变成一条
稳定的单行，实时写着进度、金额、速率与剩余时间 → 你按 Ctrl-C，它优雅地停住并告诉你
"再次运行即可从断点继续" → 结束时给你一张结算单，而不是一句"完成"。

**FIRST VIEWPORT**
`booktran run` 的第一屏：两行——
第一行是项目与阶段摘要（`继续翻译 · 待补 1,133 段 · 目标 简体中文 · 模型 claude-sonnet-4-5`），
第二行是成本闸（估算区间 + 预算上限 + 三个选项）。
确认后，屏幕收成一条实时覆盖的单行：
`⠿ 翻译  简体中文  1,284/2,417 段  ▕██████████▏ 53%   $2.14   41.2k tok/min   剩余 ~8m32s`
进度、金额、速率、ETA 同行；`--json` 模式下同一信息变为逐行 NDJSON 事件。

**FORM**
形式 = 挑战者 #4「磁带 j-card」的账本语法，与我的接地方向 #7 融合后胜出；
我的七条接地方向按共鸣排序如下（roll 分配到第 7 条）：
1 印刷所排版工单 · 2 图书馆借阅卡 · 3 编辑部红笔批注本 · 4 誊写手抄本格线 ·
5 译稿三校样 · 6 航海日志 · 7 **单色印刷账本行（进度与花费同行）**。
挑战者裁定：#4 j-card **wins**（受众识别=誊写员手边的账本与跑马灯；
产品清晰度=贴边右对齐的时长即费用）→ 其"贴边数字 + 单一折页"语法成为基底，
在终端里落成"单行实时覆盖 + 右侧贴边数字"；
#5 机场指示牌 **competitive**（保住产品清晰度轴：只显示前方选择与距离）→
raise："作业行只显示当前阶段与剩余分钟数，不罗列全部阶段"；
#6 Ikeda 数据极乐 **competitive**（保住产品清晰度轴：选中一列聚焦数字）→
raise："`--json` 事件流里用量按阶段/模型分列，便于下游聚焦"；
#1 地铁大字报 / #2 流媒体封面墙 / #3 星图注记 **declined**（两轴皆失，
终端媒介上更不可行）→ 无保留。
