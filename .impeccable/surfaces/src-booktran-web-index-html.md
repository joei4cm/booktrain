# Surface brief — booktran WebApp（v2 工作台）

## 范围与访客模式
本地单用户、仅 127.0.0.1 的书目翻译工作台。模式 **Operate**（主）+ **Read**（书页预览）。
覆盖：书架 / 工作台 / 模型 / 成本 四个目的地 + 常驻作业条。目标视口 1440，兼容 1024 / 768 / 390。
不含：账号、协作、云端、移动原生。

## 受众、任务、证据与约束
- 受众：刚拖进一本书的普通读者（要敢按下开始），以及守着长任务的译者（要知道花了多少钱）。
- 任务：把一本书翻成目标语言，并在过程中随时看见进度、花费与排版效果。
- 证据：真实书目进度、真实 token 与费用（`usage.jsonl`）、真实书页渲染产物。无演示数据、无虚构评价。
- 约束：前端 Vite + TypeScript；后端 FastAPI；密钥不回显；不引入账号体系；
  文案层 i18n（zh-CN 默认，en-US 预留）；对比度 ≥4.5:1；状态不得只用颜色表达。

## 选定方向与难忘瞬间
**方向**：一张摊在书桌上的校样稿纸——白纸、蓝笔批注、右侧账本。
**难忘瞬间**：翻译进行中，书页上的段落**逐段落定**（180ms 淡入上移），
未译处留铅笔灰的待定标记；点击页边批注即跳到右栏的校对问题。
（详见 `docs/ux/web.md` §4.1）

## 未决
- 字体：书页用 Source Han Serif / Noto Serif CJK，需确认随包分发许可还是系统回退。
- 深色模式：v1 明确不做（理由见 `docs/ux/web.md` §7.4），待渲染器支持反色纸张时再议。
- 截图与社交预览图：开源发布前必须真跑。

## Direction contract

**THESIS**
这不是仪表盘，是一张摊开的稿纸。工具区密集冷静、书页安静留白；
两侧并置的张力就是产品性格——左边是机器的账本，右边是即将读的书。
拒绝"指标卡 + 卡片墙 + 居中转圈"的仪表盘默认排布。

**OWN-WORLD**
校样稿纸（galley proof）与磁带 j-card 的混合系统：白纸为唯一真实表面，
工作台是冷灰"桌面"；蓝黑圆珠笔（靛蓝 #2C5AA0）承担批注、选中与主行动，
铅笔灰承担未译/待复核的"待定"；唯一暖色留给纸质纸面本身。
数字一律贴右页边、等宽对齐，紧贴装订线外缘，像 j-card 上的曲目时长。
分隔靠细线与留白，不靠卡片与阴影；面板圆角 6px，控件 3px，胶囊仅限计数徽标。

**STORY**
你把书拖进来 → 屏幕先告诉你这次大概要花多少钱 → 你按下开始 →
书页在你眼前长大 → 每一处可疑的译文被蓝笔标出 → 你就地接受或改写 →
最后一页是排好版的成品。理解、相信、动手，全程不需要离开这一页。

**FIRST VIEWPORT**
进入工作台的第一屏：顶栏 48px（项目名 + 目标语言切换器 + 命令面板 + 设置）；
左侧导航轨 64px（书架/工作台/模型/成本，图标+文字，纵向）；
主区三栏 240 / 1fr / 340——左栏章节大纲与阶段轨道（可折叠到 48px），
中栏**一张居中的白纸书页**（68ch / 720px 上限，衬线 18px/1.9，真实页边距与页码，
底部翻页器），右栏校对问题清单（可折叠）；
底部常驻作业条 44px：阶段轨道 + 进度条 + 百分比 + 已花金额 + ETA。
主行动（开始/继续翻译）位于顶栏右侧；成本数字与它同一视觉行，永远不折叠。

**FORM**
形式 = 挑战者 #4「磁带 j-card」的校样卡系统语法，与我的接地方向 #7 融合后胜出；
我的七条接地方向按共鸣排序如下（roll 分配到第 7 条）：

5 译稿胶印校样 · 6 航海与星图注记 · 7 **校样稿纸 + 账本（摊开的书页）**。
